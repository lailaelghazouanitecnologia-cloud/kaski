# HLE Module System

## NID (Numeric ID) System

Every PSP syscall is identified by a 32-bit NID. NIDs are generated by hashing the function name with a specific algorithm.

```
Function Name          NID
───────────────────────────────────
sceKernelCreateThread  0x446D8DE6
sceKernelStartThread   0xF475845D
sceKernelExitThread    0xAA73C935
sceIoOpen              0x109F50BC
sceIoRead              0x6A638D83
sceIoClose             0x810C4BC3
```

## Module Registration

Modules are registered using decorators:

```typescript
import { hleModule, nativeFunction } from '../manager/ModuleManager';

@hleModule('ThreadManForUser')
export class ThreadManForUser {
  readonly name = 'ThreadManForUser';

  private ctx!: EmulatorContext;

  init(ctx: EmulatorContext): void {
    this.ctx = ctx;
  }

  @nativeFunction(0x446D8DE6, 150)  // NID, firmware version
  sceKernelCreateThread(): number {
    const name = this.ctx.readString(this.ctx.arg(0));
    const entry = this.ctx.arg(1);
    // ... implementation
    return threadUid;
  }
}
```

## Registering Modules

```typescript
const ctx = new EmulatorContext(memory);

// Register modules
ctx.moduleManager.registerModule(SysMemUserForUser);
ctx.moduleManager.registerModule(ThreadManForUser);
ctx.moduleManager.registerModule(IoFileMgrForUser);

// Initialize all modules
ctx.moduleManager.initAll();
```

## Calling Syscalls

When the CPU encounters a syscall instruction:

```typescript
// In interpreter
if (isSystemCall(instruction)) {
  const nid = getNidFromImportTable(address);
  const result = ctx.moduleManager.call(nid);

  if (result instanceof Promise) {
    // Async operation - suspend thread
    await result;
  } else {
    // Sync operation - set return value
    ctx.setReturnValue(result);
  }
}
```

## Function Signature Patterns

### Simple return
```typescript
@nativeFunction(0x3FC9AE6A, 150)
sceKernelDevkitVersion(): number {
  return 0x06060010;  // 6.60
}
```

### With arguments
```typescript
@nativeFunction(0x71BC9871, 150)
sceKernelChangeThreadPriority(): number {
  const thid = this.ctx.arg(0);     // $a0
  const priority = this.ctx.arg(1); // $a1
  return threadManager.changePriority(thid, priority);
}
```

### With string argument
```typescript
@nativeFunction(0x446D8DE6, 150)
sceKernelCreateThread(): number {
  const namePtr = this.ctx.argPtr(0);
  const name = this.ctx.readString(namePtr);
  // ...
}
```

### Async operation
```typescript
@nativeFunction(0x6A638D83, 150)
sceIoRead(): number | Promise<number> {
  const fd = this.ctx.arg(0);
  const dataPtr = this.ctx.argPtr(1);
  const size = this.ctx.arg(2);

  return fileManager.read(fd, size).then(result => {
    // Copy to memory
    return result.data.length;
  }).toPromise();
}
```

### 64-bit return
```typescript
@nativeFunction(0x27EB27B8, 150)
sceIoLseek(): number | Promise<number> {
  // ...
  return fileManager.seek(fd, offset, mode).then(result => {
    // Set v0 and v1 for 64-bit result
    this.ctx.setReturnValue64(result.position.low, result.position.high);
    return result.position.low;
  }).toPromise();
}
```

### Output pointer
```typescript
@nativeFunction(0xACE946E8, 150)
sceIoGetstat(): number | Promise<number> {
  const filePtr = this.ctx.argPtr(0);
  const statPtr = this.ctx.argPtr(1);  // Output

  return fileManager.stat(file).then(result => {
    // Write to output struct
    this.ctx.write32(statPtr + 0, result.stat.mode);
    this.ctx.write32(statPtr + 4, result.stat.size);
    return 0;
  }).toPromise();
}
```
